> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct every independently reproducible 0.9.1 audit defect, harden characteristic solving against silent false negatives, make symbolic/unit/Piecewise behavior internally coherent, establish permanent multi-Python CI, and release EngCalc 0.9.2 without adding new product features.

**Architecture:** Correct behavior first in the existing module, then split the characteristic engine behind its stable import surface. Roots and intersections converge on one zero-set discovery/validation/fallback/merge policy; Piecewise topology and unit-literal resolution become shared services rather than operation-specific exceptions. def unit_literal_overrides(self, expression, overrides=None):
